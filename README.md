# MyForest 小程序设计说明

## 项目定位

面向**两人共用**的微信小程序，把计划表、专注计时、已完成记录和共享可见串成闭环。

核心流程：

1. 邀请码进入同一共享空间
2. 语音 / 手动创建计划 → 确认后写入计划表
3. 手动完成或专注计时完成 → 写入已完成表
4. 按用户、标签、时间维度统计

第一版不做小组管理、社交、排行榜等复杂能力。

## 技术栈

| 层 | 方案 |
|---|---|
| 前端 | 微信小程序原生，TypeScript + Less |
| 后端 | 微信云开发（云数据库 + 云函数） |
| 语音 | 微信语音识别 / 同声传译 |
| AI | DeepSeek，仅云函数调用，Key 不下发客户端 |

## 入口与共享

- 未验证邀请码：只显示邀请码页
- 验证通过：绑定 `sharedSpaceId`，同空间两人互相可见计划与状态
- 第一版邀请码写死固定值，后续可改为云数据库配置

## 页面结构

### 首页

今日概览（计划数、已完成、专注时长、逾期）+ 两个主操作：

- **长按语音**：识别 → DeepSeek 生成计划草稿 → 用户确认后保存
- **开始计时**：选正/倒计时、深度/浅度模式后进入计时页

另展示最近计划与对方状态预览。

### 计划表

- **月视图**：日历摘要，每格最多 2 条（头像 + 标签），超出 `+N`；有逾期显示 `!`
- **日视图**：独立页面，左侧时间轴 + 三列看板
  - **具体时段**：`startTime`–`endTime`，支持两人重叠分列；**同用户精准时段不可重叠**
  - **上午/下午/晚上**：时段型计划
  - **全天**：当天随时可完成
- 成员筛选：全部 / 我 / 对方（绿 / 蓝区分，逾期统一红色）
- 计划操作：编辑、开始计时、标记完成、删除

计划时间分三类：**精准时间**、**时段**（上/下/晚）、**全天**。

### 已完成 / 统计 / 设置

- **已完成**：按日期分组；支持成员、完成方式、时间筛选；逾期完成保留标记
- **统计**：专注时长只计「计时完成」；手动完成只计次数；可按日/月/年、成员、标签查看
- **设置**：昵称头像、邀请码、标签管理、通知授权、默认计时模式等

## 计划状态与规则

| 状态 | 含义 |
|---|---|
| `pending` | 待开始 |
| `in_progress` | 专注中 |
| `completed` | 已完成（有计划打勾 + 已完成记录） |
| `overdue` | 已逾期 |
| `cancelled` | 已取消 |

逾期：有结束时间的计划超时未完成；仅日期无时刻的当天事项在 23:59 后未完成。逾期不自动进已完成表，完成后标记「逾期完成」。

提醒（第一版）：有 `date` + `startTime` 的计划，开始前 5 分钟订阅消息提醒。

## 完成与计时

**手动完成**：计划卡片 → 确认 → 打勾 + 写已完成表。

**计时完成**：选模式 → 计时（可暂停）→ 结束确认（标签、详情、是否关联计划）→ 打勾 + 写已完成表。选「不算完成」则不写入。

| 模式 | 行为 |
|---|---|
| 深度计时 | 退出小程序自动暂停 |
| 浅度计时 | 退出小程序继续计时 |

标签分**共用**（空间内可见）和**私人**（仅创建者）。计划主题标签默认作为完成标签。

## AI 能力边界

**只做**：口述 → 计划草稿（日期、时段、模糊时间、标签、时长等结构化字段）。

**不做**：直接写已完成、开始计时、标记完成、改统计、静默保存。必须经用户确认页才入库。

```mermaid
flowchart LR
  voice[长按语音] --> stt[语音识别]
  stt --> ai[云函数 DeepSeek]
  ai --> draft[计划草稿]
  draft --> confirm[用户确认]
  confirm --> db[(计划表)]
```

AI 返回固定 JSON（`intent` / `sourceText` / `plans` / `warnings`）。模糊时间放 `timeText`，不得硬猜成 `startTime`/`endTime`。详见 `miniprogram/utils/deepseek.ts`。

## 数据模型（云数据库）

| 集合 | 核心字段 |
|---|---|
| `users` | openid, nickname, avatarUrl, sharedSpaceId, inviteVerified |
| `invite_codes` | code, sharedSpaceId, enabled, expiresAt |
| `plans` | userId, sharedSpaceId, title, tag, date, startTime, endTime, timeText, status, reminder… |
| `focus_sessions` | planId, startAt, endAt, tag, timerMode, pauseRecords… |
| `completed_records` | planId, tag, detail, completionMode, actualMinutes, wasOverdue… |
| `tags` | name, color, visibility（shared/private） |

## 第一版范围

**做**：邀请码、双人共享、语音/手动计划、月/日视图、完成与逾期、计时（深/浅）、已完成表、自定义标签、基础统计、计划提醒。

**不做**：建群/成员管理、聊天、排行榜、付费、防作弊、AI 自动完成/计时。
